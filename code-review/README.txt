## Code review exercise. No installs needed.

Three files are about to be merged and shipped: main.tf and lambda.tf (one
OpenTofu/Terraform config) and deploy.yml (the CI pipeline). Review them as you
would a teammate's pull request. For each problem you find, say what it is, why
it matters, and how you would fix it. Talk through your thinking as you go.

Start with whichever file you like. Prioritize: tell us which issues you would
block the merge on and which can wait.
